# 0007 STT เลือกโมเดลตามภาษาที่ผู้ใช้เลือก (ไทย/อังกฤษ)

สถานะ: ยอมรับ (2026-11-10)

ปุ่ม ไทย | EN ด้านบนเปลี่ยนทั้งภาษา UI, ชื่อ Station, ตัวอย่างคำสั่ง และภาษาที่ส่งให้ STT (ไม่ใช้ auto-detect เพราะ Whisper อ่านคลิปไทยสั้นๆ เป็นภาษาจีน)
Server ใช้ Python worker ตัวเดียวที่โหลดโมเดลค้างไว้ (`scripts/stt_worker.py`) และเลือกโมเดลตามภาษา:

| ภาษา | โมเดล | ถูก Station | เดินผิดที่ | เวลา (median) |
|---|---|---|---|---|
| th | biodatlab/distill-whisper-th-medium (MIT, 962 MB) | 25/26 | 0 | 1.3 s |
| th | Whisper tiny (เดิม) | 17/26 | 3 | 2.5 s |
| en | openai/whisper-small.en (Apache-2.0, 967 MB) | 26/26 | 0 | 0.7 s |

ตัวเลือกที่วัดแล้วไม่เลือก: whisper-th-small-combined (24/26, เร็วกว่า), whisper-th-medium-combined (24/26, ช้ากว่า), whisper-base.en (26/26 แต่เล็กกว่า ทนสำเนียงน้อยกว่า)

ข้อจำกัดของการวัด: เสียงสังเคราะห์ macOS (ไทยมีแค่เสียง Kanya ที่ 2 ความเร็ว, อังกฤษ Samantha/Rishi) ยังไม่ได้วัดกับเสียงคนจริงและเสียงรบกวนในสถานที่
รายละเอียด: `npm run bench:stt -- .scratch/stt-bench rama2-park th <model…>`

รายละเอียดทางเทคนิค:
- ใช้ float32 บน MPS: fp16 ให้ผลเป็น `!!!!` ทั้งหมด
- ไม่ส่ง prompt ชื่อ Station ให้โมเดล เพราะ prompt ทำให้โมเดลเดาชื่อสถานที่ผิด
- โหลดครั้งแรก ~7–13 วินาที หน้าเว็บจึงเรียก `POST /api/stt/warmup` ตอนเปิดและตอนเปลี่ยนภาษา
- `STT_ENGINE=tiny` หรือ worker เปิดไม่ได้ → ใช้ Whisper tiny แทน

## ภาคผนวก (2026-11-10): ความแม่นยำของคำสั่งท่าทาง (Gesture)

วัดด้วยคลิปเสียงสังเคราะห์ 42 คลิป (7 ท่า × 3 แบบประโยค × 2 ภาษา) นับว่าถูกเมื่อ parser ได้ท่าที่ตั้งใจ
`npm run bench:stt -- .scratch/stt-gestures rama2-park <th|en> <model…>` (ตั้ง `BENCH_PROMPT=…` เพื่อวัด priming)

| ภาษา | โมเดล | ไม่มี prompt | prompt คำท่าทางภาษาอังกฤษ | ทำท่าผิด |
|---|---|---|---|---|
| th | distill-whisper-th-medium | 18/21 | 0/21 (โมเดลวนซ้ำ “ส ส ส …”) | 0 |
| th | Whisper tiny | 6/21 | – | 0 |
| en | whisper-small.en | 14/21 | **20/21** (Station ยัง 26/26) | 0 |
| en | Whisper tiny | 15/21 | – | 0 |

ผลที่ตัดสิน:
- ภาษาอังกฤษส่ง prompt เป็นรายการคำสั่งท่าทางคำเดียวจาก Gesture Library (`wai, wave, point, …`) เพราะคำสั้นคำเดียวถูกได้ยินเป็น “Why?”, “Oh.”, “coin.” ถ้าไม่มี prompt
- ภาษาไทยไม่ส่ง prompt ใดๆ ให้โมเดลกลั่น (ทุก prompt ทำให้ผลพัง)
- ที่ยังพลาดคือคำไทยพยางค์เดียวหรือคำที่สระเพี้ยน (เต้น→“ติน”, โบกมือ→“บวกมือ”, ไหว้→“ว่าย”) และ “dance” คำเดียว ไม่มีครั้งไหนที่ทำท่าผิด (ตกไปเป็นคำถามแทน) ประโยคสองคำขึ้นไป (“โบกมือหน่อย”, “dance for me”) ถูกทั้งหมด
- parser: คำท่าทางที่พูดก่อน “ไป” (“ชี้ไปทางนั้น”) เป็นท่าทาง ไม่ใช่การเดิน เว้นแต่ชื่อ Station หลัง “ไป” ตรงชัด (≥0.85)
