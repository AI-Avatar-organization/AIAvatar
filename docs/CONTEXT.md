# AI Avatar 3D

ภาษากลางของโครงการวิจัยเรื่องการสร้างและนำประสบการณ์การนำชมใน 3D World กลับมาใช้ซ้ำ ในบริบทพิพิธภัณฑ์ มรดกทางวัฒนธรรม และการเรียนการสอนในมหาวิทยาลัย

## Language

**Creator**:
อาจารย์ที่สอนเรื่องสถานที่ผ่านการแชร์จอในห้องเรียน ใช้โหมด Record สอนและอัด Replay เป็น Primary User ของโครงการ (ADR 0013) ภัณฑารักษ์และนักการศึกษาเป็นกลุ่มถัดไป เนื้อหาชุดแรก (Map เอกสาร Replay ตัวอย่าง) ทีมโครงการสร้างให้ Creator แค่เปิดใช้หรืออัดเพิ่ม (ยังไม่ยืนยันภาคสนาม)
_Avoid_: User, ผู้ใช้, ผู้สร้าง Map

**Visitor**:
มีตัวละคร (Avatar) ของตัวเองในโลก 3D เสมอ ตอนดู Replay จะเห็นตัวเองกับ Avatar ที่ถูกอัดไว้เดินคู่กัน (ตอนนี้เล่นคนเดียว อนาคตมี Login และ Multiplayer ที่แต่ละคนมีตัวละครไม่ซ้ำกัน) นักศึกษาที่ดูอาจารย์สอนในโหมด Record ผ่านจอที่แชร์และทบทวนด้วย Replay เป็นหลัก นักท่องเที่ยวและผู้ที่เดินทางลำบากเป็นกลุ่มถัดไปที่ใช้เนื้อหาเดียวกันผ่าน AI Tour เป็น Secondary User ของโครงการ
_Avoid_: User, ผู้ใช้, Learner, End User

**AI Tour**:
ประสบการณ์หลักของโครงการ ที่ Guide พา Visitor ไปตาม Station เรียงตาม Tour Script หยุดทำท่าแล้วเล่า Narration ของแต่ละ Station และตอบคำถามจากข้อมูลที่ Creator ให้ไว้ ส่วนที่ AI ทำคือการตอบคำถามเท่านั้น
_Avoid_: Chatbot, Virtual Tour

**Guide**:
Avatar รูปร่างคนที่นำทัวร์ เดินนำ ทำ Gesture และพูด เป็นร่างแบบเดียวกับ Avatar ในโหมด Record และ Replay ต่างกันแค่ผู้สั่ง (ADR 0011)
_Avoid_: หิ่งห้อย, Chatbot, ไกด์ AI (เมื่อหมายถึงร่าง)

**Record (โหมด)**:
โหมดที่ Creator บังคับ Avatar เองแบบสด เช่น อาจารย์แชร์จอสอนหน้าชั้น สั่งด้วยการกดค้างไมค์แล้วพูด (เฉพาะตอนกดเท่านั้นที่เป็นคำสั่ง) หรือคลิก Pin และปุ่มท่าทาง เข้าโหมดแล้วซ้อมได้โดยยังไม่อัด จนกด ⏺ เริ่มอัด, ⏸ พักระหว่างอัด (ช่วงพักไม่ถูกบันทึก) และ ⏹ หยุดเพื่อบันทึกเป็น Recording ซึ่งเก็บทุกอย่างรวมถึงเสียงที่ใช้สั่ง
_Avoid_: Live (ชื่อเดิม), Real-time mode

**Tour Script**:
ลำดับ Station ของ AI Tour ที่ Creator กำหนด พร้อม Gesture ที่ Guide ทำเมื่อถึงแต่ละ Station Visitor ขอแวะนอกลำดับได้
_Avoid_: Route (เมื่อหมายถึงลำดับเรื่องเล่า ไม่ใช่เส้นทางเดิน)

**Speaker Label**:
ป้ายบนจอที่บอกว่าเสียงที่กำลังได้ยินมาจากไหน: "🎙 <ชื่อ Creator> (อัดไว้)" เมื่อเล่น Recording หรือ "🤖 Guide AI ตอบจากเอกสาร" เมื่อ AI ตอบ เพื่อให้ Visitor ตัดสินได้ว่าควรเชื่อแค่ไหน

**Source**:
แหล่งอ้างอิงจริงของเอกสารแต่ละย่อหน้า (URL) ค้นจากชื่อหรือภาพของ Asset และ Station คำตอบของ AI แสดง Source ทุกครั้ง Station ที่ไม่มี Source ไม่มีเอกสารและไม่มี Prompt Preset

**Current Station**:
Station ที่ Guide ยืนใกล้ที่สุดใน Map ใช้เป็นบริบทเมื่อ Visitor ถามว่า "ที่นี่คืออะไร" ไม่ได้มาจาก GPS ของ Visitor
_Avoid_: ตำแหน่งปัจจุบัน (คลุมเครือว่าของ Guide หรือของคนจริง)

**Voice Profile**:
เสียงของคนจริงที่ Creator อัดไว้พร้อมความยินยอมของเจ้าของเสียง Author เลือก Voice Profile ที่ใช้งานได้ครั้งละหนึ่งเสียง ใช้กับทุกคนที่พูด Narration และคำตอบของ AI (รวมถึง Avatar ของ Visitor) ทั้งไทยและอังกฤษ จนกว่าจะมี Login ให้แต่ละคนเลือกเสียงของตัวเอง
_Avoid_: เสียงสังเคราะห์ (เมื่อหมายถึงเสียงที่โคลนจากคนจริง)

**Prompt Preset**:
คำถามแนะนำที่ขึ้นในกล่องแชท (Chat Box) เมื่อ Avatar ของ Visitor เข้าใกล้ Station สำคัญ (Station ที่มีเอกสารอ้างอิงจริง) กดแล้วส่งข้อความผ่านกล่องแชทเดิม (มีปุ่ม Copy ด้วย) Avatar ของ Visitor เป็นผู้พูดคำตอบ แล้ว AI เล่าเรื่องของ Station นั้นจากเอกสารอ้างอิงจริงที่แนบกับ Map แทนการพูดหรือพิมพ์ถามเอง

**Narration**:
สิ่งที่ Guide เล่าเมื่อถึง Station ถ้า Station มี Replay ใช้ช่วงของ Recording ล่าสุดตั้งแต่ Avatar ถึง Station จนเริ่มเดินออก (ระบบตัดเอง) ถ้าไม่มีใช้เสียงสังเคราะห์อ่านความรู้ของ Station
_Avoid_: Answer (คำตอบของคำถามไม่ใช่ Narration)

**Station**:
จุดหนึ่งใน 3D World ที่มีความหมายและมีความรู้ของสถานที่ผูกอยู่
_Avoid_: POI, จุดหมาย

**Replay**:
ประสบการณ์หลักคู่กับ AI Tour ที่เล่นซ้ำการเดิน ท่าทาง และเสียงของ Avatar ที่ Creator อัดไว้ในโหมด Record ในโลก 3D ไม่ใช่วิดีโอ 2D แต่ละ Recording มีลิงก์ของตัวเอง เปิดได้โดยไม่ต้องมีบัญชี ระหว่าง Pause ถาม Guide ได้ โดยใช้ Station ที่ Avatar ยืนอยู่ ณ จุดนั้นเป็น Current Station
_Avoid_: Reply, วิดีโอบันทึก

**Map**:
โลก 3D Low Poly หนึ่งผืนที่รวมภูมิทัศน์และ Asset ทุกชิ้นของพื้นที่ไว้ด้วยกัน (เช่น อุทยาน ร.2 อัมพวา มีถนน แม่น้ำ ต้นไม้ และอาคารมรดกหลายหลัง) เก็บเป็น Map Package `maps/<mapId>/` (map.json, scene.glb, knowledge/, documents/) เพิ่ม Map ได้โดยไม่แก้โค้ด อาคารเดี่ยวไม่ใช่ Map แต่เป็น Asset ที่วางลงใน Map
_Avoid_: Scene, ฉาก (เมื่อหมายถึงหน่วยข้อมูล)

**Pin**:
เครื่องหมายบนจอที่แสดง Station ให้คลิกหรือเรียกด้วยเสียง Station คือความหมาย ส่วน Pin คือสิ่งที่เห็น

**Voice Command**:
ประโยคที่ผู้ใช้พูดแล้วถูกแปลงเป็น Intent (goto, gesture, ask, stop) ด้วย keyword/regex จากคำศัพท์ของ Map และ Gesture Library

**Gesture**:
ท่าทางของ Avatar ที่เป็นคลิป animation บนโครงกระดูกของ Avatar ในคลัง Gesture Library ไม่ขึ้นกับว่ามาจาก Motion Source ไหน
_Avoid_: Animation (เมื่อหมายถึงท่าที่สั่งได้)

**Motion File**:
ไฟล์ท่าทางที่ Author นำเข้า (.glb / .fbx / .bvh) ก่อนถูกแปลง (retarget) เป็น Gesture บนโครงกระดูกของ Avatar
_Avoid_: Gesture (เมื่อยังไม่ได้แปลง), clip (เมื่อหมายถึงไฟล์ต้นทาง)

**Motion Source**:
แหล่งที่สร้าง Motion File เช่น Mixamo, QuickMagic, Rokoko เก็บในช่อง `source` ของ Gesture ไม่ตรงกับแหล่งที่รู้จักให้ใช้ `other`
แต่ละแหล่งมีสถานะสิทธิ์ใช้งาน: เชิงพาณิชย์ได้ หรือ ทดลองเท่านั้น

**Prop**:
Asset ที่ติดกับตัวนักแสดงระหว่างเล่น Gesture (กีตาร์, ไม้กลอง) Author นำเข้าผ่านระบบ Input พร้อมจุดยึด (มือซ้าย, มือขวา, Hips, พื้นหน้านักแสดง) และตำแหน่ง/มุม
_Avoid_: Asset (เมื่อหมายถึงของที่วางใน Map)

**T2 Avatar**:
Avatar แบบ Avaturn T2 ที่มี ARKit blendshapes + Visemes จึงขยับปากได้ Avatar ที่ไม่ใช่ T2 เล่น Gesture ได้แต่ขยับปากไม่ได้

**Author**:
ทีมงานที่เปิด Author mode (`?author=1`) แก้ Map และนำเข้า Motion File ผู้ชมทั่วไปนำเข้าไม่ได้

**Guest**:
Visitor ที่ยังไม่ได้เข้าสู่ระบบ MANGOs ใช้ทุกอย่างของการชมสถานที่ได้ และเลือก Avatar ของระบบได้
_Avoid_: Anonymous, ผู้ใช้ไม่ระบุตัว

**Member**:
Visitor ที่มี MANGOs Session ได้ฟีเจอร์ของสมาชิก เช่น ใช้ Avatar จากคลังของตัวเองใน MANGOs และ Multiplayer ในอนาคต ระบุตัวด้วยรหัสผู้ใช้ MANGOs ไม่ใช่อีเมล
_Avoid_: User, Account

**MANGOs Session**:
การเข้าสู่ระบบ MANGOs ครั้งเดียวที่ใช้ได้กับทุกเว็บใต้ mangosgo.com แอปนี้ไม่มีการเข้าสู่ระบบของตัวเอง
_Avoid_: Login ของแอป, App session

**Recording**:
ไฟล์ที่ Replay ใช้เล่น เก็บ Event Timeline ของ Avatar และเสียงพูดพร้อมคำบรรยาย ผูกกับ Map เวอร์ชันแรกแก้ไขไม่ได้ ลบแล้วอัดใหม่เท่านั้น

**Asset**:
วัตถุ 3D ที่วางลงใน Map เช่น อาคาร รถ ของตกแต่ง ไฟล์อยู่ใน Map Package หรือคลังกลาง `assets/places/`
_Avoid_: Map (เมื่อหมายถึงอาคารเดี่ยว)

**Connector**:
ทางเชื่อมระหว่างระดับที่วาดไว้ใน map.json (บันได ทางลาด) ใช้เมื่อพื้นที่เดินได้ที่สร้างอัตโนมัติ (navmesh) เชื่อมสองระดับไม่ได้

**Concurrent Visitors**:
จำนวน Visitor ที่เปิดหน้าเว็บอยู่พร้อมกันในช่วงเวลาหนึ่ง ภาระหลักคือการส่งไฟล์ Map และ Avatar ครั้งแรก เพราะโลก 3D แสดงผลในเครื่องของ Visitor เอง
_Avoid_: Concurrent users, ผู้ใช้พร้อมกัน

**Simultaneous Voice Commands**:
จำนวน Voice Command ที่ถูกส่งมาถอดเสียงในวินาทีเดียวกัน เป็นภาระที่หนักที่สุดของระบบ ต่างจาก Concurrent Visitors
_Avoid_: Concurrent users (เมื่อหมายถึงคนที่กำลังพูด)

**End-to-End Latency**:
เวลาตั้งแต่ Visitor พูดจบจนถึง Avatar เริ่มทำตาม Voice Command (เดินหรือเล่น Gesture)
_Avoid_: Response time (คลุมเครือว่านับถึงตอนไหน)

**STT Service**:
บริการถอดเสียงของภาษาเดียว (เช่น STT Service ภาษาไทย, STT Service ภาษาอังกฤษ) แยกจากหน้าเว็บ และเพิ่มจำนวนได้อิสระตามภาระของภาษานั้น
_Avoid_: STT worker (เมื่อหมายถึงทั้งบริการ), Model server

**Browser STT Fallback**:
การถอดเสียงด้วยความสามารถของเบราว์เซอร์เอง ใช้เมื่อ STT Service ของภาษานั้นไม่ว่างทุกตัว Visitor จึงไม่ต้องรอคิว แต่ความแม่นยำต่ำกว่า STT Service
_Avoid_: Queue, คิวสำรอง

**Simultaneous Questions**:
จำนวนคำถามถึง AI ที่ส่งมาพร้อมกัน เป้าหมายรอบ 3: Concurrent Visitors 40 คน ถามพร้อมกันไม่เกิน 10 (ห้องเรียน 1 ห้อง) Prompt Preset ตอบทันทีจาก cache คำถามพิมพ์เองได้ตัวหนังสือภายใน 5 วินาที เกินกำลังแล้วต้องตอบเป็นตัวหนังสือก่อน ไม่ให้ใครรอเงียบ
_Avoid_: Concurrent users, คิว

**Model Router**:
โมเดลภาษาตัวเล็กที่คัดกรองคำถามก่อน: มีคำตอบใน cache ไหม เป็นคำสั่งเดินหรือไม่ เป็นเรื่องนอก Map หรือไม่ (นอกเรื่องตอบสั้นๆ เองได้) คำถามจริงเรื่องสถานที่ส่งให้โมเดลตัวใหญ่ตอบทุกข้อ ตัวเล็กไม่ตอบเรื่องสถานที่เอง เพราะทดสอบแล้วแต่งข้อมูล (ADR 0015)
_Avoid_: โมเดลสรุปให้ตัวใหญ่ (แบบที่ไม่ได้เลือก)

**เดินตาม (Follow)**:
โหมดใน Replay ที่ Avatar ของ Visitor เดินคู่ Avatar ที่ถูกอัดเอง ห่าง 1.5 ม. ด้านหลังเยื้องขวา เปิดเป็นค่าเริ่มต้นเมื่อกด ▶ (วาปไปข้างตัวที่ถูกอัดก่อน) กด WASD แล้วหลุดไปเดินเอง กดปุ่ม "เดินตาม" แล้ววาปกลับ
_Avoid_: Auto-follow camera (กล้องอย่างเดียว)

**Manual Control**:
การบังคับ Avatar ด้วยคีย์บอร์ด W เดินหน้า S ถอยหลัง A/D หัน เดินได้เฉพาะพื้นที่เดินได้ (navmesh) ใช้ได้ทั้งโหมดปกติ Record และ Replay และถูกอัดใน Recording
_Avoid_: Free mode

**โหมดบิน (Flight)**:
กด F แล้ว Avatar กางแขนบิน Space ค้างลอยขึ้น ปล่อยแล้วลอยค้าง Shift ค้างลดระดับ F อีกครั้งร่อนลงพื้น สูงสุด 30 ม. บินผ่านหลังคาได้ ท่าบินทำด้วยโค้ดจนกว่าจะมีคลิปจาก QuickMagic
_Avoid_: Noclip

**Flash Speed**:
ตัวเลือกที่ทำให้ทุกการเคลื่อนที่ของ Avatar เร็วขึ้น 3 เท่า (เดินด้วยคีย์บอร์ด เดินอัตโนมัติ เดินตาม และบิน) จำค่าต่อเบราว์เซอร์ (เดิมหมายถึง "ไปถึงทันที" กับการเดินอัตโนมัติอย่างเดียว)
_Avoid_: Teleport

**Chat Dock**:
แถบไมค์/พิมพ์ด้านล่างจอ ประวัติแชทซ่อนเป็นค่าเริ่มต้น เปิดด้วยปุ่ม 💬 (มีตัวเลขข้อความใหม่) ปุ่ม Prompt Preset เป็นแถวเล็กเหนือแถบเมื่ออยู่ใกล้ Station ที่มี Source ตอน Guide พูดต้องไม่มีอะไรบัง CC
_Avoid_: Chat window, Chat panel
